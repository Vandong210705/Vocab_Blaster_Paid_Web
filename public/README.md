# VOCAB BLASTER

Game luyện gõ kiểu Typing Shooter.

## Cách chạy
1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome/Edge.
3. Dán từ theo dạng `english|nghĩa tiếng Việt`.
4. Bấm **BẮT ĐẦU BẮN**.

## Hỗ trợ tệp
- TXT: `abandon|từ bỏ`
- CSV: `abandon,từ bỏ`
- JSON: `[{"en":"abandon","vi":"từ bỏ"}]`

## Gameplay
- Nhiều nhân vật: gà, vịt, heo, ếch, robot, ma, alien, khủng long...
- Gõ chữ cái đầu để khóa mục tiêu.
- Gõ hết từ để bắn hạ.
- Hạ xong hiện nghĩa tiếng Việt ngay tại vị trí mục tiêu.
- Có điểm, combo, level, mạng, hiệu ứng đạn/nổ, đọc phát âm tiếng Anh.
- `Backspace` để sửa; `Esc` để tạm dừng.

Bộ từ được lưu trong trình duyệt bằng localStorage.
